perf(search): cache processed search terms for fuzzy search

Implemented a bounded LRU cache (max size 250) using Map to memoize
the regex compilation and array mapping for search query terms
in advancedFuzzySearch.

To prevent redundant string splitting, toLowerCase() calls, array
allocations, and regex instantiations for identical search queries
across consecutive search filtering cycles.

The searchUtils.benchmark script showed an improvement in execution
times, dropping from an average baseline of 168567.36ms down to
167190.00ms across 10 cycled queries on 26,000 items. Due to Fuse.js
initialization occurring sequentially for every filter, the measurable
gain is marginal but still mitigates object allocation and GC pressure.
