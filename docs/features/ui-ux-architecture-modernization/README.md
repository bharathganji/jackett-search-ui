# UI/UX Architecture Modernization Documentation

- [Concepts Brief (concepts_brief.md)](./concepts_brief.md): Initial feature concept exploration and trade-off analysis.
- [Design Draft (design_draft.md)](./design_draft.md): Early design RFC draft.
